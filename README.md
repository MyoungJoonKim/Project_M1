### \# PROJECT\_M1 (슬라임키우기)

Unity 기반 2D 모바일 뱀서라이크 액션 로그라이크 RPG 개인 프로젝트입니다.

플레이어는 전투 중 지속적으로 등장하는 몬스터를 처치하고 경험치를 획득하여 레벨업하며, 무작위로 제공되는 액티브 스킬과 패시브 능력을 선택해 캐릭터를 성장시킵니다.

게임은 웨이브와 라운드 단위로 진행되며, 라운드 후반에는 보스 전투와 별도의 이벤트 전투가 발생합니다. 전투 종료 후에는 보상을 획득하고 로비로 복귀하는 구조입니다.
